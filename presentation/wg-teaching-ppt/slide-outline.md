# WG-01～WG-17 教學簡報大綱

## 簡報定位
- 受眾：高中生
- 語氣：白話、少術語、先講用途再講做法
- 風格：白底為主、深藍與青綠點綴、圖像大於文字
- 頁數策略：`26` 頁，平均每個大模組 `3～5` 頁

## 模組與頁面配置

### 1. 開場與地圖
1. **封面**
   - 主題：從 Python 基礎到會記憶的 AI Agent
   - 用途：建立期待感，說明這不是單一程式題，而是一條能力升級路線
   - 視覺：AI 助教 + 終端機 + 對話泡泡的主視覺

2. **今天會走過哪 7 個模組**
   - 對應：全體 `WG-01～WG-17`
   - 用途：先給整張學習地圖
   - 視覺：7 段式路線圖 / 等級升級時間軸

### 2. 模組一：先讓程式開口說話
3. **WG-01｜按下啟動鍵**
   - 對應：`WG-01`
   - 重點：`if __name__ == "__main__"`、`print()`
   - 視覺：直接執行 vs import 的雙路圖

4. **WG-02～WG-03｜字串先有名字，再把名字縫進句子**
   - 對應：`WG-02～WG-03`
   - 重點：變數、f-string、賦值順序
   - 視覺：變數盒子 + 句子模板填空

### 3. 模組二：替 Agent 備料
5. **WG-04｜把工具裝進專案**
   - 對應：`WG-04`
   - 重點：`uv add`、頂層 import、專案根目錄
   - 視覺：專案資料夾 + 終端機安裝示意

6. **WG-05｜讀設定，但不把金鑰秀出來**
   - 對應：`WG-05`
   - 重點：`.env`、`load_dotenv()`、`os.getenv()`、安全輸出
   - 視覺：鎖頭 + 遮罩過的 key 卡片

### 4. 模組三：把流程收乾淨
7. **WG-06～WG-07｜有鑰匙才往下走**
   - 對應：`WG-06～WG-07`

   - 視覺：流程圖，有 key / 沒 key 兩條路

### 5. 模組四：真的開始和模型說話
8. **WG-08｜第一通打進大模型**
   - 對應：`WG-08`

    - 對應：`WG-01～WG-10`

### 6. 模組五：短期記憶與角色設定
